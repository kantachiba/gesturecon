# 作品説明文（約800字）

本作品「ジェスチャーコン」は、micro:bit v2 に内蔵された 3 軸加速度センサーのデータを AI（ニューラルネットワーク）でリアルタイム識別し、手の動き（ジェスチャー）だけで外部機器を非接触操作するシステムです。

最大の特長は、リアルタイム OS「μT-Kernel 3.0」のタスク管理を活用した点にあります。センサー収集（優先度 1）・AI 推論（優先度 5）・出力制御（優先度 8）・省電力管理（優先度 10）の 4 タスクを独立動作させることで、AI の推論処理中（約 80ms）もセンサーデータを 20ms 周期で取りこぼしなく収集し続けます。従来のシングルタスク処理では実現が困難だった「推論と入力の完全並行動作」を RTOS によって初めて可能にしています。

AI モデルには Edge Impulse を用いました。50Hz でサンプリングした加速度データ 2 秒分（100 サンプル）をスペクトル解析で特徴量抽出し、Dense ニューラルネットワーク（64→32→4 ユニット）で「振る・叩く・回す・待機」の 4 クラスを識別します。INT8 量子化により、モデルサイズを約 10KB・推論 RAM を約 15KB に抑え、128KB という micro:bit v2 の限られたメモリ内に収めています。クラウドを介さずマイコン内で処理が完結するため、反応遅延は約 100ms 以下を実現しています。

本システムは感染症対策としての「非接触スイッチ」や、身体障害者・高齢者向けの「ジェスチャー操作インターフェース」として実用的な社会課題解決を目指しています。μT-Kernel 3.0 の「軽快さと力強さ」を最大限に活かし、組み込み AI とリアルタイム OS の相乗効果を実装しました。
